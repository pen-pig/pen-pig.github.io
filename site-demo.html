与真实版本的区别

真实版本是跑在社团服务器上的 PHP 应用，数据存在 JSON 文件里。这里是界面示意导览——布局仿照真实页面重画，数据是编的，点不了。

为什么网页里不能真跑

GitHub Pages 只托管静态文件，没有 PHP 运行时，也不能连数据库。要真跑需要一台 PHP 服务器——社团的那台就是了。

技术栈

PHP 5.6+ · JSON 文件存储 · Bootstrap UI · GD 图像处理 · session 会话。代码由 AI 生成，我负责需求与维护。
