在浏览器里运行 CeruliaOS

下面是一台真实的 x86 模拟器（v86，WebAssembly）。点击启动，它会加载 CeruliaOS 的磁盘镜像，走完和真机一样的引导链：BIOS → MBR → boot sector → stage2 → kernel。你在屏幕上看到的一切，都是这台"虚拟机"现场算出来的。

VM // X86-32 128MB RAM DISK: RAW IMAGE v86 / WASM

READY

点击下方按钮，在网页里启动 CeruliaOS。

IDLE

这是怎么做到的

整个系统跑在 v86 里——一个用 WebAssembly 编译的 x86 模拟器，连 BIOS 都是真的。磁盘镜像和你在 VMware / QEMU 里启动的是同一个文件，只是换了个"硬件"。

没有任何录屏成分：屏幕上的每个字符都是模拟器执行 CeruliaOS 机器码的输出。

操作方式

启动后点击一下屏幕，键盘输入就会送进虚拟机（Esc 或点击屏幕外可释放）。CeruliaOS 有自己的 shell，输入 help 看看能做什么。

模拟的是 32 位 PC：方向键、回车、字母数字键都可用；部分组合键（如 Ctrl+Alt+Del）由浏览器占用。

镜像说明

磁盘镜像从 CeruliaOS 的构建产物生成：源码目录运行 python tools/make_image.py 得到 os-image.bin（引导扇区 + stage2 + 内核，无数据分区，约 0.8MB），托管在本站 assets/os/。浏览器版不带数据分区，因此文件系统相关命令暂不可用；shell、selftest 等内核功能完整。
