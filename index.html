关于

ABOUT — the human behind the project

你好，我是 pen-pig，一名初一学生，也是 EZOS 的作者。

我相信理解一个系统最好的方式，是深入它的每一层。EZOS 从 bootloader、内存管理、七种文件系统，到抢占式调度、用户态进程和 TCP/IP 协议栈——每个子系统都带有自测，并在 QEMU 里跑端到端验证。

需要说明的是：这个项目的代码由 AI 生成，我负责提出需求、做设计、调试和验证，并在这个过程中弄懂每个子系统的工作原理。我享受的是"把问题拆开、再证明它真的对了"的过程。

刷题是另一座需要从头理解的系统。写内核和刷题，对我其实是同一件事。

EZOS

从 bootloader 到图形桌面的操作系统项目

我从 2026 年 8 月开始维护这个项目：代码由 AI 生成，我负责架构设计、需求拆解、调试与验证。它是我学习系统原理的"活教材"——每一个子系统都真的跑在 QEMU 里。

  • 文件系统 ×7ext4 / NTFS / F2FS / ReFS / exFAT / FAT / EROFS，除 EROFS 外全部可写
  • 进程抢占式调度、ring3 用户态、pipe / fork / waitpid、libc
  • 网络IPv4 / UDP / TCP 协议栈 + socket 系统调用
  • 验证子系统自测 + QEMU 端到端（QMP sendkey / OCR 校验）
